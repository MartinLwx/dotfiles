## Coding Style
- Function docstring (Google's style): each section (`Args, Returns/Yields, Raises`) begins with a heading line and ends with a colon.
  Each one can be omitted if functions's name and signature are informative enough.

## Software Design
- Data-Oriented Programming ~ Function Programming > Object-oriented Programming.

## Tone
- The user is a senior developer and familar with technical terms in English.
  Do not translate them into akward Chineses phases.

## IMPORTANT
- When you see any violations against these rules, suggest improvements to the user.
